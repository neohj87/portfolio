Raw data

원시 데이터 직접 처리

완벽히 정제된 데이터가 아닌 공통 제공 원시 데이터를 다루며 정제·변수 해석·통계적 사고력을 직접 적용함.

Domain knowledge

임상병리 + 병원 행정 실무 경험 결합

임상병리학 전공 지식과 약 4년간의 병원 행정 업무(건강보험공단 금연치료 사업 참여, 환자 설문 지원·현장 관리) 경험을 바탕으로 가설을 설계함.

Validation

분석 결과의 현실 검증

분석 결과가 단순 숫자에 그치지 않도록, 실제 건강 상태 및 의료 현장에서 관찰되는 현상을 얼마나 반영하는지 검증하는 것을 목표로 함.

데이터 이해

목표 변수 및 핵심 의학 지표

Label(흡연 여부)을 목표 변수로 두고, 분석 전 각 지표의 의학적 의미와 정상 범위를 먼저 정리함.

Label (흡연 여부)
1=흡연자, 0=비흡연자 — 본 프로젝트의 목표 변수
BMI (체질량지수)
키·몸무게 기반 비만도 지표, 체형 평가 기본 수치
공복 혈당
8시간 이상 금식 후 측정, 당뇨 진단 기본 지표 (정상 70~100 mg/dL)
중성지방 (Triglyceride)
체내 저장 지방, 높을수록 심혈관 질환 위험 증가 (정상 150 mg/dL 미만)
혈청 크레아티닌
근육 대사 노폐물, 신장 기능 평가 지표 (정상 0.5~1.2 mg/dL)
총콜레스테롤 / HDL / LDL
혈관 건강 반영. 총콜레스테롤 240 미만, HDL 40~90, LDL 130 미만(mg/dL)
헤모글로빈 (Hemoglobin)
적혈구 산소 운반 단백질, 성별 정상범위 차이 큼 (남 13~17.5, 여 12~15.5 g/dL)
간 효소율
간세포 손상 시 혈액 유출 효소 수치, 간 건강 평가에 활용
전처리

변수 특성에 따른 결측치 처리

단순 행 삭제 시 데이터 손실·왜곡 우려 → 변수 특성을 고려해 각기 다른 방식으로 대체

변수처리 방식사유
혈압중앙값(Median) 대체극단값의 영향을 최소화하기 위함
시력최빈값(Mode) 대체가장 많이 나타나는 값으로 대체
중성지방나이대별 평균값 대체연령에 따라 수치 차이가 크다고 판단
공복 혈당전체 평균값 대체전반적인 분포 수준을 반영

이어서 BMI 기준 체중 상태(저체중~3단계 비만, 6단계)와 연령 기반 나이대(20대~70대 초과, 7단계) 파생변수를 생성하여, 연령·체형에 따른 집단 비교가 가능하도록 데이터를 구성함.

데이터 한계 대응

성별 데이터 부재 문제와 보완

탐색적 데이터 분석(EDA) 과정에서 발견한 핵심 데이터 설계 한계

핵심 문제 — 신체검사 데이터에서 성별은 매우 중요한 기준 변수이지만, 해당 데이터에는 성별 정보가 존재하지 않았음. 헤모글로빈은 남녀 정상 범위 자체가 다르기 때문에, 성별을 고려하지 않으면 분석 결과가 왜곡될 수 있는 상황.

대응: K-Means를 활용한 Gender Proxy 생성 — 키·몸무게 분포 차이에 착안하여 군집화로 성별을 간접 추정함.

한계 인식 — 체격이 큰 여성, 체격이 작은 남성은 반대 군집으로 오분류될 가능성이 있음을 인지함. K-Means는 데이터 부족 상황에서 시도할 수 있는 보완 방법일 뿐, 실제 성별 데이터를 완벽히 대체할 수는 없다는 점을 결론으로 명시함.
가설 검정

세 가지 가설과 통계적 검증

가설 1 — 흡연자는 헤모글로빈 수치가 높을 것이다채택
근거흡연은 체내 산소 공급을 감소시키며, 이를 보상하기 위해 적혈구 생성이 증가한다는 의학적 기전에 근거함.
검정 결과 (t-test)흡연자 집단의 헤모글로빈 수치가 비흡연자보다 통계적으로 유의하게 높게 나타남.
가설 2 — 흡연자는 중성지방 수치가 높을 것이다채택
근거흡연이 지질대사에 영향을 미쳐 혈중 지방 수치를 증가시킬 수 있다는 점에 근거함.
검정 결과 (t-test)흡연자 집단에서 중성지방 평균이 더 높게 나타났으며, 통계적으로도 유의미한 차이를 보임.
가설 3 — BMI는 흡연 여부와 큰 차이가 없을 것이다채택
발견된 의문상관관계 분석에서 흡연 여부와 몸무게는 비교적 높은 관련성을 보임. 몸무게가 포함된 BMI 역시 강한 관련성을 보여야 하는 것 아닌지 의문이 발생함.
검증 과정직접 t-test를 수행해 재검정한 결과, 흡연자와 비흡연자 간 BMI 차이는 통계적으로 유의하지 않음을 확인함. 데이터 오류·전처리 오류 가능성을 먼저 배제하는 과정을 거침.
최종 해석흡연자는 상대적으로 키·몸무게가 큰 집단에 많이 분포하지만, 동시에 흡연이 대사 활동에 영향을 미쳐 체중 증가를 일부 상쇄시키는 효과가 존재해 BMI에서는 차이가 크게 나타나지 않은 것으로 해석함. 단순 숫자 비교만으로는 발견하기 어려운 현상을 데이터 검증을 통해 확인함.
인사이트

프로젝트를 통해 얻은 관점

01

데이터를 정확히 바라보는 중요성

요단백 변수는 숫자로 저장되어 있었지만 실제로는 등급형 범주 데이터였음. 동일한 유형의 변수(혈압: 최대값·최소값, 간효소율: AST·ALT)도 각각 수치화 기준이 통일되지 않았음을 확인함.

02

데이터 수집 설계의 중요성

성별 정보 부재 문제를 K-Means Gender Proxy로 보완했지만 실제 성별 정보를 완벽히 대체할 수는 없었음. 분석 단계보다 수집 설계 단계가 결과 품질을 더 크게 좌우할 수 있음을 확인함.

03

다각적 변수 수집의 필요성

흡연 여부는 혈액검사 수치 몇 개만으로 설명하기 어려움. 성별·연령·직업·생활습관· 사회경제적 수준·흡연량·흡연 기간 등이 함께 고려되어야 함을 확인함.

04

실무 경험과 데이터 분석의 연결

건강보험공단 금연치료 사업의 흡연 기간·흡연량·생활환경·금연 의지 설문 경험이 단순 행정 절차가 아닌, 분석 정확도를 높이는 실질적 정보로 연결됨을 재확인함.

데이터 분석은 알고리즘 적용이 아니라 "왜 이 분석이 필요한가"를 규명하고, 데이터 특성에 맞는 기법을 선택하는 과정이라는 점을 확인함.

코드 실행 여부에 만족하지 않고 데이터의 구조적 한계를 검토하며 합리적인 분석 방향을 도출하는 접근을 취함. 이를 계기로 분석 기법의 원리와 적용 범위를 보다 정밀하게 이해하기 위한 학습을 지속하고 있음.
