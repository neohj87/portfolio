EMR Support & Product Troubleshooting

네오소프트뱅크사용자의 문제를 재현 가능한 조건으로 바꾸고, 개발팀과 함께 반복 장애를 해결하였습니다

병·의원 고객의 EMR 사용을 지원하고 PACS와 외부 수탁검사 연동을 담당하였습니다. 별도의 기획자가 없는 환경에서 현장의 정제되지 않은 요구와 오류 상황을 개발자가 확인할 수 있는 정보로 구조화하고, 실제 고객 환경에서 테스트하여 수정버전이 안정적으로 적용되는 과정까지 지원하였습니다.

Project Overview

문의에 답하는 데서 끝내지 않고,반복 오류의 조건과 연결구간을 추적하였습니다

의료기관의 업무는 EMR 한 프로그램만으로 끝나지 않습니다. PACS, 검사장비, 외부 수탁검사업체와 여러 프로그램이 연결되어 있기 때문에 같은 증상처럼 보여도 원인은 서로 다른 구간에 있을 수 있었습니다.

병·의원 사용자의 기능 문의와 오류를 일평균 약 25건, 많을 때는 하루 약 40건까지 응대하였습니다. 접수와 수납뿐 아니라 진료실과 진료지원부서에서 사용하는 기능까지 폭넓게 지원하였으며, 신규 고객의 프로그램 설치와 환경설정, 기존 고객의 업데이트 기능 적용을 안내하였습니다.

진료 중 오류가 발생하면 환자 접수와 진료가 지연될 수 있기 때문에 일반적인 사용문의와 구분하여 실시간으로 우선 대응하였습니다. 전화와 온라인 채널로 상황을 확인한 뒤 필요하면 바로 원격으로 접속하여 사용자의 업무가 이어질 수 있도록 빠르게 조치하였습니다.

오류가 반복될 때는 사용자의 설명만 개발팀에 전달하지 않았습니다. 문제가 발생한 고객 환경에 직접 접속하여 어떤 화면과 업무 단계에서 문제가 나타나는지 확인하고, 발생 시점과 재현 절차, 정상 환경과의 차이를 정리하였습니다.

특히 PACS와 진단검사처럼 외부 시스템이 연결된 업무에서는 EMR 내부 기능, 브로커, 검사장비 연동업체와 수탁검사업체 중 어느 구간에서 정보가 달라지는지 확인하였습니다. 이를 통해 개발팀이 원인을 좁힐 수 있도록 지원하고, 수정버전 적용 후에는 실제 환경에서 정상 작동과 재발 여부를 다시 확인하였습니다.

현장의 증상을 그대로 전달하는 것이 아니라, 개발자가 확인할 수 있는 발생조건·재현절차·연동구간으로 바꾸는 역할을 수행하였습니다.

01 · Customer & Integration Support

EMR 문의부터 PACS와 검사결과 연동까지,의료기관의 실제 사용환경을 지원하였습니다

01

EMR 고객지원

외래와 진료지원 기능의 사용법을 안내하고, 전화·온라인 채널·원격접속을 통해 오류와 환경설정을 확인하였습니다.

02

PACS 설치와 연동

의료기관에 PACS를 설치하고 영상 전송과 조회가 이어지도록 브로커와 EMR의 연동상태를 확인하였습니다.

03

수탁검사 연동

외부 수탁검사업체로 전달되는 검사 의뢰와 회신되는 결과가 EMR에 정상적으로 연결되는지 확인하고 연동을 지원하였습니다.

일일 문의 대응평균 약 25건업무가 집중되는 날에는 최대 약 40건까지 응대
지원 업무 범위접수부터 진료지원까지접수·수납·진료·진료지원부서의 EMR 문의와 오류 대응
긴급 오류 대응실시간 우선 처리진료 흐름에 영향을 주는 오류는 원격접속을 통해 신속하게 확인

02 · Requirement Translation

정제되지 않은 요구를 그대로 넘기지 않고,업무 목적과 대안을 함께 정리하였습니다

별도의 기획자가 없는 상황에서 사용자는 필요한 기능을 업무용어나 개인적인 해결방법으로 설명하는 경우가 많았습니다. 먼저 사용자가 왜 해당 기능을 요청하는지, 기존 업무에서 어느 부분이 불편한지와 요청한 방식으로 해결하려는 문제가 무엇인지 확인하였습니다.

요청을 무조건 수용하지는 않았습니다. 기존 기능으로 해결할 수 있거나 다른 사용자와 전체 업무 흐름에 영향을 줄 수 있는 요청은 그대로 구현하기 어려운 이유를 설명하였습니다. 병원 현장경험을 바탕으로 실제 업무에서 사용할 수 있는 다른 방법을 제안하고, 개발팀에는 그 대안의 기술적 가능성과 영향범위를 확인하였습니다.

개발이 필요한 경우에는 사용자의 표현을 화면, 업무 순서, 발생조건과 기대결과로 나누어 전달하였습니다. 개발팀의 답변은 다시 의료기관 사용자가 이해할 수 있는 언어로 풀어 설명하며 양측의 기대를 조율하였습니다.

사용자와 개발팀 사이에서 말을 전달하는 역할이 아니라, 요구의 목적을 파악하고 구현 가능한 해결방식으로 바꾸는 역할을 수행하였습니다.

요구사항 정리 기준

  1. 요청이 발생한 실제 업무 확인
  2. 기존 기능과 해결 가능성 검토
  3. 다른 사용자와 업무에 미칠 영향 확인
  4. 현장 기준의 대안 제시
  5. 개발 가능성과 적용방식 협의

불가능하다는 답변으로 끝내지 않고, 사용자가 하려는 업무를 유지할 수 있는 대안을 함께 찾았습니다.

03 · Repeated Issue Resolution

반복되는 오류를 개별 문의로 처리하지 않고,발생조건과 외부 연동구간을 추적하였습니다

다음 사례는 고객 환경에서 반복되던 문제를 재현하고 개발팀 및 외부 연동업체와 원인을 확인한 대표적인 경험입니다.

CASE 01

업데이트 이후 진료지원 출력 오류

업데이트 이후 특정 고객 환경에서 진료지원 관련 출력이 되지 않는 문제가 약 한 달간 반복되었습니다. 단순 재설치나 일회성 안내로 종료하지 않고 실제 고객 환경에 원격으로 접속하여 출력과정을 반복 테스트하였습니다.

오류가 발생하는 화면과 조건을 확인해 개발자에게 전달하고, 원인 확인과 수정버전 개발을 지원하였습니다.

새로운 버전을 고객 환경에 적용한 뒤 실제 출력이 정상적으로 이루어지는지 확인하였습니다.

CASE 02

진단검사 결과 매핑 불일치

외부에서 수신되는 진단검사 결과의 매핑이 업데이트마다 달라지는 문제가 반복되었습니다. 변경된 결과와 업데이트 시점, EMR과 검사장비 사이의 연동구간을 확인하였습니다.

확인 결과 장비 연동업체가 사전 공유 없이 연동을 적용한 사실을 파악하였습니다. EMR 업데이트 자체가 아니라 외부업체의 미통보 변경이 결과 매핑을 어긋나게 한 원인임을 개발팀에 전달하였습니다.

반복 오류의 책임구간을 구분하고 개발팀이 대응할 수 있도록 외부 연동 변경사항을 명확히 정리하였습니다.

CASE 03

PACS 브로커 자동 종료

PACS 브로커가 자동으로 종료되면서 영상 연동이 중단되는 문제가 반복되었습니다. 고객 환경에서 브로커의 실행상태와 종료 상황을 확인하고 개발자와 문제조건을 공유하였습니다.

원인 분석과 개선과정에 참여하고 수정된 버전을 실제 환경에 적용하여 영상 연동이 유지되는지 점검하였습니다.

의료기관 사용자가 장애를 발견한 시점부터 수정버전의 실환경 확인까지 후속 과정을 이어서 관리하였습니다.

04 · QA & Documentation

수정된 기능을 다시 확인하고,반복 문의를 사용자가 참고할 자료로 정리했습니다

업데이트 전후로 기능을 테스트하고 기존 업무가 정상적으로 유지되는지 확인하였습니다. 수정버전은 개발환경에서 동작한다는 사실만으로 종료하지 않고, 문제가 발생했던 의료기관 환경에 적용하여 실제 업무에서 정상적으로 사용할 수 있는지 점검하였습니다.

반복되는 사용 문의와 업데이트로 달라진 기능은 사용자 매뉴얼과 안내자료로 정리하였습니다. 문의가 들어올 때마다 같은 내용을 개별 안내하는 데서 그치지 않고, 사용자가 업무 중 다시 확인할 수 있도록 절차와 화면 기준으로 작성하였습니다.

이 과정에서 고객지원 중 확인한 현장 문제를 개발팀에 전달하고, 개발된 결과를 다시 사용자에게 적용하는 양방향 연결 역할을 수행하였습니다.

업무 과정에서 협업한 대상

병·의원 사용자

사용환경과 업무 흐름을 확인하고 기능 안내, 원격지원, 오류 재현과 수정버전 검증을 진행하였습니다.

사내 개발팀

오류 발생조건과 재현절차, 사용자 요구의 목적과 기대결과를 정리하여 전달하고 개선 결과를 확인하였습니다.

PACS 관련 업체

영상 전송과 조회에 필요한 설치환경과 브로커 연동상태를 확인하고 장애 대응을 지원하였습니다.

외부 수탁검사업체

검사 의뢰와 결과가 EMR에 정상적으로 전달되도록 연동상태와 결과 수신을 확인하였습니다.

검사장비 연동업체

결과 매핑 불일치 사례에서 변경 시점과 연동 적용내역을 확인하여 문제 발생구간을 구분하였습니다.

내부 고객지원 구성원

반복 문의와 변경사항을 공유하고 동일한 기준으로 대응할 수 있도록 안내내용을 문서화하였습니다.

Core Contribution

의료현장을 이해하는 고객지원 경험을 바탕으로,
사용자의 언어를 개발 가능한 조건과 검증절차로 바꾸었습니다.

EMR, PACS와 진단검사가 연결된 환경에서 오류의 발생조건과 연동구간을 확인하고, 개발팀과 외부업체가 원인을 좁힐 수 있도록 지원하였습니다. 또한 수정버전을 실제 의료기관 환경에서 검증하여 현장의 문제 해결이 제품 개선으로 이어지도록 하였습니다.
